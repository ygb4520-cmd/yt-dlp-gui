# yt-dlp GUI

A small window for downloading video or audio with [yt-dlp](https://github.com/yt-dlp/yt-dlp). Paste links (one per line), choose Video or Audio only, pick a save folder, press Download.

- Audio is saved as it comes from the site (usually .m4a), no conversion.
- Video: with ffmpeg it joins the best picture and sound; without ffmpeg it saves a single file with sound if the site offers one (on YouTube that is up to 360p).
- YouTube links work best with Node.js installed.
- **Spotify (Mac app and Windows version):** paste a Spotify song, album or playlist link and the app reads the song list from Spotify's public page (no account or key), then looks for each song on YouTube **in this order: YouTube Music, then a lyric video, then an official video, then any music video, and last the plain top result**. Each place only counts if its length is within a few seconds of Spotify's (10 s for YouTube Music and lyric videos, 20 s for videos), and covers, live versions, remixes, karaoke and so on are skipped unless the song's own name says so. The row shows where the song came from, for example "Done (lyric video)". For albums and playlists a window lists the songs so you can **tick the ones you want** (turn that off with "Choose Spotify songs"). Spotify songs are always saved as audio (m4a) with the **title, artist, album artist, track number, year and cover art written into the file**, with no ffmpeg needed (the Mac app uses macOS's audio framework; the Windows version writes the MP4 tags itself). Albums and playlists go into a folder named after them. Album links also give the album name and track numbers; single songs and playlist songs get cover art, artist, title and year but no album name (Spotify's page does not give it). Artist, podcast and short links are not supported, and Spotify's public page may list only the first ~100 songs of a very large playlist.
- **Search music by name (Mac app and Windows version):** press **Search...** next to Paste, pick Songs, Albums, Artists or Playlists, and type a name. Songs, albums and artists come from Apple's free catalog (it covers Hebrew/Yiddish and other smaller artists far better than the other free catalogs I tried), playlists from Deezer. No account or key. Tick what you want and press Add: each pick becomes a line like `itunes:album:1441164426 # The Beatles - Abbey Road` in the link box (you can delete lines). For an artist, pick them, press "Show albums", and untick any album you do not want (duplicate editions like Deluxe and Remastered are folded into one). Press Download and each line is turned into its songs, found in the same order as Spotify songs (YouTube Music, lyric video, official video, music video, top result) and tagged with title, artist, album, track number, year and cover art. Pasting Spotify links works exactly as before and can be mixed with searched items.
- A YouTube download that fails with "403 Forbidden" is retried automatically (up to 3 tries), because YouTube does that at random.
- **Audio quality:** choose "m4a" (plays everywhere) or "best available" (often .webm/opus). YouTube audio tops out around 128-160 kbps either way. **Video quality:** choose a max height; without ffmpeg, YouTube video is limited to the single-file formats it still offers (up to 360p).

## Updates
Both versions check GitHub for a newer release when they start (and when you press **Check for updates**), and show a banner with **Update now**. The Mac app downloads the new app, checks it (it must be this app, newer, correctly signed and match GitHub's checksum), swaps itself and reopens. The Windows version replaces its own files and restarts. To publish an update: raise the number in `VERSION` and in `yt_gui.py`, commit and push, then run `NOTES="what changed" ./release.sh`, which builds, tags `v<version>` and uploads `yt-dlp-GUI-mac.zip` and `yt-dlp-GUI-windows.zip`. Download the first copy from the [latest release](https://github.com/ygb4520-cmd/yt-dlp-gui/releases/latest); on a Mac, right-click the app and choose Open once (it is signed ad hoc, not by Apple).

## Mac (native Swift app)
`cd mac-swift && ./build.sh` builds a universal `build.noindex/yt-dlp GUI.app` (the `.noindex` folder keeps Spotlight from listing a second copy) (needs Xcode or the Command Line Tools). Copy it to Applications. No Python needed. It looks for `yt-dlp` on your PATH, in `~/Applications`, and in Downloads; or press "Locate yt-dlp...".
Logic check without a window: `"build.noindex/yt-dlp GUI.app/Contents/MacOS/yt-dlp-gui" --selftest`

## Windows (Python)
Install Python from python.org, then double-click `Start yt-dlp GUI.bat` (runs `yt_gui.py`, standard library only). The same file runs on a Mac with python.org Python, but Apple's built-in Python has an old Tk that shows a blank window on recent macOS, which is why the Mac app is native.
Logic check: `python3 yt_gui.py --selftest`

## Debug driver (Mac app)
For testing without anything appearing on screen. Launch with `YTGUI_DEBUG_DRIVER=<scratch dir>`: the app runs with no Dock icon and fully transparent, click-through windows, writes `status.txt` (settings, link box, download rows, Search and song-picker state, logs) and `snapshot.png` (its own rendering; `snapshot_sheet.png` while a Search or song-picker sheet is open) about twice a second, and runs commands written one per line to `command.txt`. All in-process, so no Accessibility or Screen Recording permission. Inert unless the variable is set.

```bash
D=/some/scratch/dir; mkdir -p "$D"
open -g -n --env YTGUI_DEBUG_DRIVER="$D" "build.noindex/yt-dlp GUI.app"      # -g: don't steal focus; -n: separate instance
printf 'mode audio\nlinks itunes:album:1441164426 # Abbey Road\ndownload\nwaitpicker\npicktoggle 0\npickok\nwaitidle\nshot\n' > "$D/command.txt"
```
Commands: `links <text, \n for a new line>`, `addlink`, `mode video|audio`, `height`, `audioformat m4a|best`, `playlist on|off`, `asksongs on|off`, `folder`, `download`, `cancel`, `waitidle`, `wait <s>`, `search`, `closesearch`, `searchkind song|album|artist|playlist`, `query`, `dosearch`, `waitsearch`, `searchselect <i,j|all|none>`, `showalbums <i>`, `searchback`, `searchadd`, `waitpicker`, `pickall`, `picknone`, `picktoggle <i>`, `pickok`, `pickskip`, `size <w> <h>`, `shot`, `quit`. Use a new scratch folder per launch and `quit` (or `pkill -f "build.noindex/yt-dlp GUI.app"`) before relaunching after a rebuild.
